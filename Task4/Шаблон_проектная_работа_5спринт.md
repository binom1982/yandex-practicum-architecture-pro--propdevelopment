# Защита доступа к кластеру Kubernetes

| Роль                                             | Права роли                                                                                                                           | Группы пользователей                                                   |
| ---------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------- |
| `cluster-admin`<br />(уже существует) | Полный доступ (`*`) ко всем ресурсам и API группам.                                                       | `specialist-info-security`(Специалист по ИБ)                              |
| `namespace-configurator`<br />(ClusterRole)        | `create, update, delete, get, list`<br />для pods, deployments, services, secrets. Без доступа к узлам и самим NS. | `devops-engineers`(Инженеры по эксплуатации / DevOps)             |
| `cluster-viewer`<br />(ClusterRole)                | `get, list, watch`<br />для pods, deployments, services. Без доступа к secrets .                                              | `business-analysts`,`managers`(Бизнес-аналитики и Менеджеры) |
| `developer-restricted`<br />(Custom Role)          | `create, update, get, list`<br />для pods, deployments, services только в конкретном Namespace .                        | `developers`(Разработчики домена Sales/Housing/Finance)               |
