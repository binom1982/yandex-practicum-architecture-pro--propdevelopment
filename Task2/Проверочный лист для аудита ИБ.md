# Проверочный лист безопасности для бизнес-систем PropDevelopment

## Обоснование выбора разделов

Для компании PropDevelopment приоритетными являются следующие разделы, исходя из выявленных проблем (утечки данных клиентов, проблемы с API партнеров, отсутствие единого контроля доступа):

1. **I. Управление доступом:** Критично из-за жалоб на отображение данных чужих клиентов и наличия нескольких точек входа. Необходимо внедрить принцип минимальных привилегий и централизованный контроль (Active Directory/Keycloak).
2. **II. Безопасность данных:** Главный риск — утечка ПДн и смешивание данных собственников в CRM. Требуется классификация данных, шифрование и разделение контуров.
3. **III. Защита инфраструктуры:** Наличие гибридной инфраструктуры и прямых интеграций с ЖКХ-поставщиками требует строгой сегментации сети и контроля периметра (Firewall).
4. **IV. Управление инцидентами:** Реакция на инциденты конкурентов и внутренние жалобы требует внедрения SIEM и планов реагирования.
5. **V. Специфические аспекты:** Важно из-за мобильного приложения для собственников и удаленного доступа сотрудников.
